# Code of conduct

PettiBox follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive. Harassment, insults, discriminatory language and
personal attacks are not tolerated in issues, pull requests, discussions or any other project
space.

Maintainers may edit or remove comments, close threads, and block people who break these rules.
To report a problem privately, contact the maintainers through the
[GhostGram Labs GitHub profile](https://github.com/ghostgramlabs) or a private security
advisory on this repository.
