Share a link, text, image, screenshot or PDF into PettiBox from any app. It extracts text with
on-device OCR, indexes everything for full-text search, and keeps it all on your phone. Backups
can go to a local folder or, optionally, your own Google Drive.

## Build

You need:
- Android Studio Hedgehog (2023.1.1) or newer
- JDK 17
- Android SDK 35

Open this project folder in Android Studio. Let it sync Gradle, then run on a device or emulator (`minSdk 24`).

Or from a shell with the wrapper:

```bash
./gradlew :app:assembleDebug
```

On Windows PowerShell, use `.\gradlew.bat :app:assembleDebug`.

## Stack

Kotlin, Jetpack Compose, Material 3, Room with FTS4, Hilt, WorkManager, ML Kit text recognition, Coil, and Jsoup.

## Release signing and Google Drive

Debug builds need no setup. Release builds read their signing key from `local.properties`
(git-ignored) or environment variables:

```properties
PETTIBOX_RELEASE_STORE_FILE=path/to/your-release-key.jks
PETTIBOX_RELEASE_STORE_PASSWORD=...
PETTIBOX_RELEASE_KEY_ALIAS=...
PETTIBOX_RELEASE_KEY_PASSWORD=...
```

Google Drive backup signs in through an OAuth client registered to GhostGram Labs' package name
and signing certificate, so it only works in official builds. Everything else, including local
backups, works in your own builds.
